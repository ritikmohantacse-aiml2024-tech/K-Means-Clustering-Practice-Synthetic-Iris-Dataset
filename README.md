# K-Means Clustering Practice: Synthetic and Iris Datasets

## About
This repository contains my practice of K-Means Clustering using Python and Scikit-learn.

## Datasets Used
- **Synthetic Dataset:** Generated using `make_blobs()` from Scikit-learn.
- **Iris Dataset:** Built-in dataset from Scikit-learn.

## Topics Covered
- K-Means Clustering
- Elbow Method
- Data Visualization
- Feature Scaling
- Principal Component Analysis (PCA)

## Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Notebook
`K-Means_clustering.ipynb`

## Purpose
To practice machine learning concepts and understand how K-Means groups similar data points into clusters.
